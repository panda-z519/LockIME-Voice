> **Форк исходного кода LockIME Voice.** Эта производная версия GPL-3.0 добавляет настраиваемый процесс голосового ввода. `v0.1.2` предлагает предварительные установщики с ad-hoc подписью, но без Developer ID, нотаризации, Sparkle и Homebrew.

Приложение для строки меню macOS, которое **блокирует источник ввода клавиатуры**. Как только вы (или другое приложение) переключаете метод ввода, LockIME немедленно возвращает заблокированный — глобально, для каждого активного приложения или (в дополнительном расширенном режиме) для каждого URL в браузере.

> macOS 14+ · Apple silicon и Intel — отдельные приложения, скачайте файл
> `-arm64` или `-x86_64`, подходящий вашему Mac · создано на SwiftUI,
> Liquid Glass на macOS 26 (Tahoe).

## Changes in LockIME Voice

По сравнению с upstream этот форк добавляет настраиваемый голосовой источник, раздельные комбинации для LockIME и метода ввода, временное переключение источника ввода на время диктовки (по желанию, по умолчанию выключено), восстановление глобального значения из **App Rules**, повторяемые сессии с тайм-аутом, а также вывод источника по умолчанию первым с отметкой-булавкой.

```sh

```

## Features

- **Мгновенная повторная блокировка** — возвращает активный источник ввода к заблокированному в тот же момент, когда вы (или другое приложение) его меняете, — глобально или для каждого приложения.
- **Учёт конфликтов** — если другая программа снова и снова навязывает свой источник ввода (например, игра со встроенным управлением IME), LockIME замечает это перетягивание и ненадолго отступает вместо бесконечных переключений, записывая *Обнаружен конфликт* в журнал срабатываний; задайте такому приложению собственное правило *Игнорировать* или *Переключить на* для окончательного решения.
- **Правила для процессов без пакета** — программы, работающие из отдельного исполняемого файла, а не из пакета `.app` (скажем, `java` игры Minecraft, запущенная сторонним лаунчером), тоже могут получать правила: пока они запущены, окно выбора приложений показывает их под синтетическим идентификатором `process:<executable>` (например, `process:java`).
- **Блокировать или переключать** — правила для приложений и для URL могут *блокировать* источник ввода (повторно применяя его при любом отклонении) или один раз *переключать* на него при открытии приложения или страницы, а затем не мешать вам его менять.
- **Блокировать глобально или просто переключать** — задайте глобальному источнику ввода по умолчанию одно из трёх поведений: *блокировать*, чтобы закрепить его везде; *переключать*, чтобы один раз переключить вас на него каждый раз, когда приложение опирается на глобальный источник по умолчанию (у него нет собственного правила или его правило — *Использовать по умолчанию*), а затем оставить вас свободными; или **Нет** — вообще без глобального поведения: тогда LockIME действует только через ваши правила для приложений и для URL. *Переключать* активно переключает вас на него каждый раз, когда применяется значение по умолчанию; **Нет** не делает глобально ничего.
- **Гибкое сопоставление URL** — правила для URL (расширенный режим) сопоставляются по домену и его поддоменам, по точному домену, по ключевому слову домена или по регулярному выражению над всем URL, и применяются в порядке приоритета, который вы задаёте перетаскиванием, — побеждает первое совпадение.
- **Управление из строки меню** — включение/выключение, смена заблокированного источника ввода, просмотр текущего источника и счётчик срабатываний прямо в строке меню.
- **Сочетания клавиш** — настраиваемые глобальные сочетания для включения/выключения LockIME и перебора заблокированного источника ввода, а также сочетания для отдельных приложений, позволяющие переключать или удалять правило активного приложения.
- **Рабочий процесс голосового ввода** — временно переключает с повседневного источника ввода на настроенный источник с голосовым вводом, отправляет собственное голосовое сочетание этой раскладки, а затем восстанавливает повседневный источник. Поведение и сочетание, настроенные в LockIME, должны совпадать с настройками голосового ввода выбранного метода ввода.
- **Запуск при входе в систему** — стартует автоматически при входе (по умолчанию выключено).
- **Светлая и тёмная темы** — единый, нативный для системы язык дизайна, адаптирующийся к светлому и тёмному оформлению, плюс фирменная иконка приложения. См. [docs/DESIGN.md](../DESIGN.md).
- **Смена языка на лету** — мгновенно переключайтесь между 9 языками без перезапуска: English, 简体中文, 繁體中文, 日本語, Français, Deutsch, Español, Português, Русский.
- **Журнал срабатываний за 24 часа** — смотрите, что было переключено, почему и как долго.
- **Резервная копия конфигурации** — экспортируйте правила для приложений и для URL в файл `.lockime` и импортируйте их обратно; перед применением шаг предпросмотра покажет добавления, конфликты и удаления.
- **Крошечная загрузка** — всё приложение помещается в `.dmg` размером менее 3 MB.
- **Базовая блокировка не требует системных разрешений** — дополнительный расширенный режим, защищённый разрешением Accessibility, открывает более тонкие правила для URL и поля с фокусом.
- **Автоматизация** — URL-схема `lockime-voice://` позволяет другим приложениям, скриптам и Shortcuts управлять LockIME (см. ниже).

## Voice Input Workflow

Источник голосового ввода настраивается полностью; LockIME Voice не привязывается к Doubao, WeChat или другому методу ввода.

1. Откройте **Settings ▸ Voice Input** и включите сценарий.
2. Запишите **комбинацию голосового ввода метода ввода** — ту, которую ваш метод ввода использует для собственной диктовки. Сначала задайте её внутри метода ввода и держите отличной от комбинации самого LockIME.
3. Запишите **голосовую комбинацию LockIME** (в **Settings ▸ Shortcuts ▸ Global shortcuts** или на той же панели). Именно её вы нажимаете.
4. Необязательно: включите **Автоматически переключать источник ввода** и выберите голосовой источник, если это не тот, которым вы обычно печатаете. Сначала задайте глобальный источник по умолчанию в **Settings ▸ App Rules** — именно его LockIME вернёт после диктовки.
5. Разрешите отправку событий клавиатуры, когда macOS запросит разрешение.

Нажатие комбинации LockIME отправляет голосовую комбинацию метода ввода, поэтому диктовка начинается в активном методе ввода. При включённом автоматическом переключении LockIME сначала переходит на заданный голосовой источник, ждёт подтверждения macOS, а по завершении диктовки или по тайм-ауту безопасности возвращает глобальный источник по умолчанию.

Поскольку LockIME только *отправляет* эту комбинацию и никогда не перехватывает ваши нажатия, комбинации должны различаться. Одна общая комбинация возвращает конфликт: нажатие обрабатывается дважды, и macOS или метод ввода сообщает о конфликте сочетаний.

Проверяйте сценарий в TextEdit или другом простом текстовом поле. Одного появления голосовой панели недостаточно: распознанный текст должен появиться в позиции курсора.
## Comparison

Две наиболее широко используемые альтернативы LockIME — это **[Input Source Pro](https://github.com/runjuu/InputSourcePro)** и **[KeyboardHolder](https://github.com/leaves615/KeyboardHolder)**, наряду с длинным хвостом из менее известных инструментов с открытым кодом и CLI. Все они *переключают* источник ввода, когда вы перемещаетесь между приложениями или сайтами; LockIME же построен вокруг непрерывной **блокировки**, которая повторно применяет его в тот же момент, когда он отклоняется, — при этом любое правило по-прежнему может свестись к однократному *переключению*.

| | LockIME | Input Source Pro | KeyboardHolder |
|---|---|---|---|
| Цена | Бесплатно | Бесплатно | Бесплатно (пожертвование) |
| Открытый код | GPL-3.0 | GPL-3.0 | ✗ (закрытый) |
| Минимальная macOS | 14 | 11 | 10.15 |
| Размер загрузки | < 3 MB | ≈ 7.6 MB | ≈ 4.5 MB |
| Правила для приложений | ✓ | ✓ | ✓ |
| Правила для сайтов / URL | ✓ | ✓ | ✓ |
| Типы сопоставления URL | поддомен · точный · ключевое слово · регулярное выражение | поддомен · точный · регулярное выражение | домен (с подстановкой) |
| Правило для адресной строки (поле URL) | ✓ (блокировка/переключение/приоритет) | ✓ (источник по умолчанию) | — |
| Непрерывная повторная блокировка | ✓ | ✗ | ✗ |
| Блокировка *или* однократное переключение, для каждого правила | ✓ | ✗ | ✗ |
| Глобальные сочетания клавиш | ✓ | ✓ | ✗ |
| Управление из строки меню | ✓ | ✓ | ✓ |
| Экранные подсказки ввода | ✗ | ✓ | ✓ (опционально) |
| Журнал срабатываний за 24 часа | ✓ | ✗ | ✗ |
| Резервная копия / импорт конфигурации | ✓ (`.lockime`, с предпросмотром) | ✓ (экспорт/импорт + CLI) | — |
| Автоматизация через URL-схему | ✓ (`lockime-voice://`, x-callback-url) | частично (импорт `inputsourcepro://`) | ✗ |
| Языки интерфейса | 9 (смена на лету) | 6 | zh · en · ja |
| Системные разрешения | не нужны для базовой · Accessibility для URL | не нужны для базовой · Accessibility для URL | Accessibility¹ |
| Автообновление | ✗ (форк только с исходным кодом) | ✓ | ✓ |
| Активно поддерживается (2026) | ✓ | ✓ | ✓ |

¹ KeyboardHolder не документирует свои требования к разрешениям; чтение адресной строки браузера для его правил по сайтам на практике требует доступа Accessibility. «—» обозначает недокументированную возможность, а не подтверждённое отсутствие.

**Что выбрать:** у Input Source Pro самое большое сообщество и самые богатые экранные подсказки ввода; KeyboardHolder — отточенная, не требующая настройки память для приложений. Обращайтесь к LockIME, когда хотите *закрепить* источник ввода — для приложения, URL или в адресной строке, с повторным применением в тот же миг, когда что-либо его меняет, — а не только переключать его при входе.

**Другие инструменты:** [SwitchKey](https://github.com/itsuhane/SwitchKey) (только для приложений, больше не поддерживается), [Kawa](https://github.com/hatashiro/kawa) (ручное переключение по сочетаниям клавиш), InputSwitcher (freemium, только для приложений) и [macism](https://github.com/laishulu/macism) (CLI-компонент, а не графический переключатель).

> Сравнение с Input Source Pro 2.11.0 и KeyboardHolder 1.14.10, середина 2026 года — детали меняются, поправки приветствуются.

## Automation

LockIME предоставляет URL-схему `lockime-voice://`, чтобы другие приложения, скрипты, Shortcuts и лаунчеры могли управлять им — включать и выключать его, менять источник ввода, управлять правилами и считывать состояние через колбэки [x-callback-url](https://x-callback-url.com). По умолчанию она выключена — включите её в **Настройки ▸ Основные ▸ Автоматизация**.

```sh
open "lockime-voice://lock"
open "lockime-voice://lock-to-source?id=com.apple.keylayout.ABC"
open "lockime-voice://set-app-rule?bundle=com.apple.Terminal&mode=lock&source=com.apple.keylayout.ABC"
```

Полная справка: **[URL Scheme API](../URL-Scheme-API/README.ru.md)**.

## Design

LockIME следует единой системе дизайна (`Sources/LockIME/UI/DesignSystem.swift`): семантические цвета, системные материалы и SF Symbols обеспечивают адаптацию к светлой/тёмной теме; Liquid Glass зарезервирован только за плавающим/навигационным слоем. Фирменный акцентный цвет «Lock Indigo» поставляется как ассет `AccentColor`. Полная спецификация — в [docs/DESIGN.md](../DESIGN.md).

Иконка приложения генерируется программно (без дизайнерских инструментов) — пересоздайте её командой:

```sh
./scripts/make-appicon.sh   # renders the master via SwiftUI and rebuilds the appiconset
```

## Development

Требуются Xcode 26+ (само приложение нацелено на macOS 14+), а также [XcodeGen](https://github.com/yonaskolb/XcodeGen) + [xcbeautify](https://github.com/cpisciotta/xcbeautify) (`brew install xcodegen xcbeautify`).

```sh
make gen     # generate LockIMEVoice.xcodeproj from project.yml
make build   # build (Debug)
make run     # build & launch
make test    # run unit tests
make archive # ad-hoc-signed Release archive
```

Проект Xcode генерируется из `project.yml` и не хранится в репозитории.

Интеграционные тесты, затрагивающие железо (реальное переключение TIS), исключены из `make test`; запускайте их через `make test-hw` (кратковременно меняет источник ввода).

## Architecture

- **LockIMEKit** (статическая библиотека) — чистая, полностью покрытая модульными тестами логика, использующая только системные фреймворки: движок блокировки, монитор приложений, правила, расширенный (Accessibility) наблюдатель, модель журнала, локализация.
- **LockIME Voice** (приложение) — `@main`, интерфейс на SwiftUI, система дизайна и тонкие интеграционные прослойки для Sparkle, KeyboardShortcuts и PermissionFlow.
